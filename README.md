# HomeBrain

אפליקציית Android לניהול פריטי הבית, מחירים ופרטי אחריות.

## מה כלול בגרסה הראשונה
- ממשק עברי מימין לשמאל בעיצוב מודרני.
- הוספה, חיפוש, סינון והסרה של פריטים.
- שמירה מקומית במכשיר.
- סיכום כמות הפריטים וכמות הפריטים עם מחיר שמור.
- GitHub Actions בונה APK בכל push ל-main או בהפעלה ידנית.

## הורדת APK
פתחו בלשונית **Actions**, בחרו **Build HomeBrain APK**, והורידו את הקובץ מתוך **Artifacts** של הריצה שהסתיימה בהצלחה.

הקובץ הוא APK מסוג debug לבדיקה, לא חבילת הפצה חתומה לחנות Google Play.
